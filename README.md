# huntress-soc-lab

Raw, in-progress working log from a live Huntress Managed Security Platform trial
(EDR / ITDR / SIEM / ISPM / SAT) — hands-on evidence for a security analyst
career path, built inside the actual product rather than a simulated range.

This is the unpolished working record, not a curated portfolio. Organized by
platform module, one folder per capability, notes added as the trial happens.

## Modules

| Folder | Covers |
|---|---|
| `EDR/` | Endpoint detection — footholds, malicious process behavior, lateral movement, ransomware precursors |
| `ITDR/` | Identity threat detection — M365/Entra account takeover, BEC, unwanted-access rules |
| `SIEM/` | Log ingestion + ES|QL search across endpoints, firewalls, cloud, SaaS |
| `ISPM/` | Identity security posture — M365/Entra misconfiguration scanning |
| `SAT/` | Security awareness training — phishing simulation + reporting |

## Trial window
EDR / ITDR / SIEM / ISPM expire 2026-08-03. SAT expires 2026-08-10.
